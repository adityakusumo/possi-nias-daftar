## 3. TROUBLESHOOTING LOG (chronological)

### T1. Git "dubious ownership" error
- **Symptom**: `fatal: detected dubious ownership in repository`
- **Cause**: git run as root on a repo owned by itpossijatim
- **Fix**: `git config --global --add safe.directory <path>`

### T2. Migration `2026_05_27_000001_fix_lomba_tables` FAILED
- **Symptom**: `SQLSTATE[42S02]: Table 'dbnias.MstPeserta' doesn't exist (ALTER TABLE MstPeserta ...)`
- **Cause**: The first restored dump (`20260429_dbnias.sql`) was a **PARTIAL dump** — only 12 of 31 tables. The legacy VB6-era tables (MstPeserta, Atlet, A3, rKwtDaftarDeposit, PesertaEmail…) didn't exist.
- **Investigation**: Compared all backups:
  - `20260414_dbnias_backup.sql` → 31 tables WITH data (full backup, Apr 14)
  - `20260429_dbnias.sql` → 12 tables with data (partial export, newer core data)
  - `20260429_dbnias_pcdit.sql` → 31 tables, NO data (structure-only)
  - `20260811_dbnias_backup.sql` → 36 tables WITH data (full, today's backup)
- **Fix (two stages)**:
  1. Hybrid import: 19 legacy tables (structure+data) extracted from the Apr 14 dump with `SET FOREIGN_KEY_CHECKS=0`, plus NIAS_STRUCT re-import (18 rows, column-mapped from the Apr 29 dump after the 04-15 recreate migration had emptied it) → migration then succeeded.
  2. Later, full restore of `20260811_dbnias_backup.sql` (user-approved, safety dump first) → complete dataset, "Nothing to migrate".

### T3. 413 Request Entity Too Large (Daftar NIAS uploads)
- **Symptom**: submitting daftar nias baru with files → HTTP 413
- **Cause**: Nginx default `client_max_body_size` is 1 MB; the form allows 5 files × 5 MB (max:5120). PHP also capped at upload_max_filesize=2M / post_max_size=8M.
- **Fix**: `client_max_body_size 30m;` in Nginx site config; `upload_max_filesize = 25M`, `post_max_size = 30M` in /etc/php/8.4/fpm/php.ini; restarted php8.4-fpm + nginx.

### T4. Gmail SMTP "535 Username and Password not accepted"
- **Symptom**: mail test failed with 535 BadCredentials
- **Cause**: typo in the Google App Password (`svpjytgaaordoqgo` vs corrected `svpjytgaoardoqgo`)
- **Fix**: corrected password in `.env` → `php artisan config:cache` → test mail sent OK.
- **Note**: app passwords require 2-Step Verification enabled; 16 chars, no spaces.

### T5. 500 Server Error on Daftar NIAS Baru submit
- **Symptom**: 500 after submitting registration
- **Log**: `League\Flysystem\UnableToCreateDirectory: Unable to create a directory at storage/app/private/nias/12`
- **Cause**: `storage/app/private/nias` existed with `drwx------` (700, itpossijatim-only). PHP-FPM runs as `www-data` → permission denied creating per-user upload folders.
- **Fix**: `chown -R itpossijatim:www-data` + `chmod -R 775 storage/app/private`; verified www-data can create dirs. Re-submit works.

### T6. Security: secrets & PII exposed in a public repo
- **Symptom/Issue**: `temp.txt` (containing DB password + Gmail app password) was committed; 13 `.sql` database dumps (athlete PII: names, NIK, emails, birthdates + password hashes) tracked in the repo; repo made public at times.
- **Actions taken**:
  - Rotated the Gmail app password (old one retired; new one only in `.env`)
  - Untracked all 13 `*.sql` dumps (`git rm --cached`, files kept on disk) + added `*.sql` to `.gitignore` — local commit `1035943`, **NOT pushed yet**
  - DB password in history is local-only (low risk)
- **Remaining (recommended)**:
  - Push the cleanup commit, then purge history with `git filter-repo` (scrub temp.txt + *.sql from all commits) + force-push; re-sync all clones afterward
  - Anyone who cloned during the public window may still hold the old secrets → rotation already done for SMTP; DB password rotation optional

### T7. Nginx server_tokens didn't take effect
- **Symptom**: `Server: nginx/1.24.0 (Ubuntu)` header still shown after adding server_tokens off
- **Cause**: the config already had a commented-out `# server_tokens off;` line; my guard `grep -q server_tokens` matched the comment and skipped the edit. Line also starts with a tab.
- **Fix**: uncommented the existing line (`s/^\s*#\s*server_tokens off;/server_tokens off;/`) → header now `Server: nginx`
